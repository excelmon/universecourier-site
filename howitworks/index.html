How it works

Universe Courier is an experiment in randomness, timing, and interpretation. Physical radioactive decay determines when a message is sent and which message is selected.

  1. Generate. An Images SI RNG-01 hardware random number generator produces values from 1 to 128 using radioactive decay events.
  2. Record. A Raspberry Pi running a .NET 10 service reads the numbers over serial and stores them in SQLite.
  3. Detect. Two consecutive numbers matching either 3 → 10 or 43 → 2 trigger a message event.
  4. Select. The three numbers immediately before the key pair seed the message retrieval algorithm, choosing from tarot cards, I Ching hexagrams, and short guidance.
  5. Deliver. The selected message is sent to a phone through an ntfy push notification.

What you're seeing on the dashboard

The dashboard displays the live number stream, recent messages, activity by hour, and the distribution of generated values. A read-only database snapshot is exported to Cloudflare R2 every five minutes, while a cached read-only feed through Cloudflare Tunnel makes new numbers visible within seconds.

The messages are interpretations selected by a random process, not predictions or evidence of a supernatural cause. The underlying number stream and trigger events can be observed directly.
